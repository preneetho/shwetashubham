# Gallery photographs

Amenity photos for the **Gallery** section go here.

The page currently expects these eight file names. Drop a real photograph in
using the matching name and it replaces the placeholder automatically — no
code change and no sheet edit needed.

```
clubhouse.jpg   pool.jpg      gym.jpg         amphitheater.jpg
playarea.jpg    gardens.jpg   reception.jpg   temple.jpg
```

To add a different amenity, add a row to the **gallery** tab of the Google
Sheet with the new file name in the `file` column, and put the file here.

Landscape photos work best. Keep each one under about 300 KB so the page
stays quick on mobile data.
