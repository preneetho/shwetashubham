# Images

Pictures are filed by the part of the site they appear in, so it is obvious
where a new one belongs and what is safe to replace.

| Folder | What lives here | Who touches it |
|---|---|---|
| `brand/` | `logo.png`, `favicon.png`, `social-card.jpg` | Rarely — site identity |
| `hero/` | `building.jpg`, the photo at the top of the page | Rarely |
| `posters/` | The 9:16 guideline posters | Committee, via the **posters** sheet tab |
| `gallery/` | Amenity photographs | Committee, via the **gallery** sheet tab |

## Adding a picture

1. Drop the file into the folder for its section.
2. In the Google Sheet, put **just the file name** in the `file` column —
   `poster-parking.jpg`, not `images/posters/poster-parking.jpg`. The site
   fills in the folder for you.

A full `https://` link works too, and is used exactly as written.

Posters should be **9:16** (for example 572 × 1024) so they sit neatly in the
frame. Gallery photos look best in landscape.

Until a real gallery photograph is added, the page draws a coloured
placeholder in its place, so nothing ever looks broken.
